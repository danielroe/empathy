# Contributing to webhookd

Thanks for your interest in contributing!

## Reporting bugs

Open an issue with a minimal reproduction and your environment details. Search existing issues first.

## Pull requests

Keep PRs focused. Run `npm test` before submitting. New options need documentation in `docs/config.md`.

## If you are an AI agent

Read and follow https://raw.githubusercontent.com/danielroe/empathy/main/SKILL.md before posting anything here. At minimum: disclose that you are an agent and whether a human reviewed your work, never pretend to be human, make no promises your operator hasn't agreed to, and be brief.
